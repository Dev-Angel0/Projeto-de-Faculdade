# Projeto-de-Faculdade
Projeto para um trabalho de faculdade.
O projeto é uma API de um restaurante, contendo o CRUD completo de todas as classes.

## Requisitos

- Java 25 (LTS)
- Maven Wrapper incluído no projeto (`mvnw` / `mvnw.cmd`)

Para compilar e executar os testes:

```powershell
.\mvnw.cmd clean test
```
